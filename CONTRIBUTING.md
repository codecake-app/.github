# Contributing

Used by every repository here that has no CONTRIBUTING file of its own.

1. **Branch** from `main`. Nobody pushes to `main` directly — a merge there can ship a build.
2. **Check** before you push: if the repository has a `Makefile`, `make` lists its targets and
   `make check` is what CI runs.
3. **Open a pull request** saying what it changes and why. Small pull requests, one concern each.
4. **Review**: a person approves and merges.
